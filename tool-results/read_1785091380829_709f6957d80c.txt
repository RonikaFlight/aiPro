   498→# 6. AUTHENTICATION SYSTEM
   499→
   500→Implement real authentication.
   501→
   502→## 6.1 Supported authentication methods
   503→
   504→Version 1 must support:
   505→
   506→* Email and password registration
   507→* Email verification
   508→* Login
   509→* Logout
   510→* Forgot password
   511→* Password reset
   512→* Google OAuth using Authorization Code with PKCE
   513→* Optional GitHub OAuth
   514→* TOTP two-factor authentication
   515→* Recovery codes
   516→* Session management
   517→* Revoke individual session
   518→* Revoke all other sessions
   519→
   520→## 6.2 Session architecture
   521→
   522→Do not store JWTs in localStorage.
   523→
   524→Use secure opaque server-side sessions.
   525→
   526→Requirements:
   527→
   528→* Generate cryptographically secure 256-bit session tokens.
   529→* Store only a hash of the session token in PostgreSQL.
   530→* Send the raw session token only in a cookie.
   531→* Cookie name:
   532→
   533→```text
   534→__Host-proofpilot_session
   535→```
   536→
   537→Cookie requirements:
   538→
   539→```text
   540→HttpOnly
   541→Secure in production
   542→Path=/
   543→SameSite=Lax
   544→No Domain attribute
   545→```
   546→
   547→Session records must contain:
   548→
   549→* User ID
   550→* Token hash
   551→* Created time
   552→* Last activity
   553→* Expiration time
   554→* IP hash
   555→* User-agent summary
   556→* Revoked time
   557→* MFA status
   558→* Session rotation counter
   559→
   560→Rotate session tokens:
   561→
   562→* After login
   563→* After MFA completion
   564→* After password change
   565→* After role elevation
   566→* After sensitive security changes
   567→
   568→Use rolling expiration with a maximum absolute lifetime.
   569→
   570→## 6.3 Password security
   571→
   572→Use Argon2id.
   573→
   574→Minimum baseline:
   575→
   576→* At least 64 MiB memory
   577→* At least 3 iterations
   578→* Parallelism of at least 1
   579→
   580→Benchmark parameters during startup or document the selected secure values.
   581→
   582→Requirements:
   583→
   584→* Minimum 12-character password
   585→* Allow password manager-generated passwords
   586→* Maximum reasonable length to prevent denial of service
   587→* Check common compromised-password patterns without transmitting the raw password
   588→* Do not force arbitrary periodic password changes
   589→* Never log passwords
   590→* Never return password hashes
   591→* Use constant-time comparisons where applicable
   592→
   593→## 6.4 Email verification and password reset
   594→
   595→Tokens must:
   596→
   597→* Be cryptographically random
   598→* Be single-use
   599→* Expire
   600→* Be stored hashed
   601→* Be invalidated after use
   602→* Be invalidated when a newer token is issued
   603→* Not reveal whether an email exists through response differences
   604→
   605→## 6.5 MFA
   606→
   607→Implement:
   608→
   609→* TOTP setup
   610→* QR code generation
   611→* Confirmation before enabling
   612→* Encrypted TOTP secret storage
   613→* Ten single-use recovery codes
   614→* Recovery codes stored hashed
   615→* Disable MFA only after password and MFA verification
   616→* Audit all MFA changes
   617→
   618→## 6.6 CSRF protection
   619→
   620→Because authentication uses cookies:
   621→
   622→* Validate Origin and Referer for state-changing requests.
   623→* Use CSRF tokens for browser requests.
   624→* Reject missing or invalid tokens.
   625→* Exempt only verified external webhook endpoints.
   626→* Do not exempt general API routes.

   630→# 7. MULTI-TENANCY
   631→
   632→ProofPilot is a multi-tenant SaaS.
   633→
   634→Every workspace-owned entity must contain `workspaceId`.
   635→
   636→Examples:
   637→
   638→* Projects
   639→* Environments
   640→* Runs
   641→* Findings
   642→* Journeys
   643→* Personas
   644→* Reports
   645→* Integrations
   646→* API keys
   647→* Secrets
   648→* Usage records
   649→
   650→Implement defense in depth:
   651→
   652→1. API workspace authorization guard
   653→2. Mandatory workspace-scoped service methods
   654→3. Database foreign keys
   655→4. PostgreSQL Row-Level Security for critical tenant tables
   656→5. Automated tenant-isolation tests
   657→
   658→Never accept `workspaceId` from the request body as trusted authorization.
   659→
   660→Resolve workspace membership from the authenticated session and route context.
   661→
   662→For RLS-sensitive queries:
   663→
   664→* Use a request-scoped transaction.
   665→* Set the current workspace using `SET LOCAL` or `set_config`.
   666→* Ensure every tenant query executes inside that transaction.
   667→* Do not disable RLS to make the ORM easier.
   668→* If the ORM cannot safely support a query, use parameterized PostgreSQL queries for that operation.
   669→
   670→Create tests proving:
   671→
   672→* User A cannot read User B’s projects.
   673→* User A cannot guess another project UUID.
   674→* User A cannot download another workspace artifact.
   675→* User A cannot access another workspace report.
   676→* A CLIENT cannot gain MEMBER permissions.
   677→* Removed members immediately lose access.

   967→# 11. SSRF AND TARGET URL SECURITY
   968→
   969→This is a critical security requirement.
   970→
   971→ProofPilot processes user-provided URLs. Treat every URL as hostile.
   972→
   973→Implement a centralized `SafeTargetUrlService`.
   974→
   975→## 11.1 URL validation
   976→
   977→For every initial URL and every redirect:
   978→
   979→1. Parse using the WHATWG URL parser.
   980→2. Normalize hostname using IDNA rules.
   981→3. Reject malformed URLs.
   982→4. Reject embedded username or password.
   983→5. Allow HTTPS by default.
   984→6. Allow HTTP only in explicitly enabled local development.
   985→7. Reject protocols including:
   986→
   987→```text
   988→file:
   989→ftp:
   990→gopher:
   991→data:
   992→javascript:
   993→blob:
   994→chrome:
   995→chrome-extension:
   996→about:
   997→ws:
   998→wss:
   999→```
  1000→
  1001→8. Reject unexpected ports unless explicitly allowed.
  1002→9. Reject hostname confusion and encoding tricks.
  1003→10. Reject excessively long URLs.
  1004→
  1005→## 11.2 IP validation
  1006→
  1007→Resolve all A and AAAA records.
  1008→
  1009→Reject:
  1010→
  1011→* Loopback addresses
  1012→* Private network ranges
  1013→* Link-local ranges
  1014→* Multicast ranges
  1015→* Carrier-grade NAT ranges
  1016→* Reserved ranges
  1017→* Documentation ranges
  1018→* Unspecified addresses
  1019→* IPv4-mapped IPv6 private addresses
  1020→* Cloud metadata endpoints
  1021→* Local Kubernetes service addresses
  1022→* Docker bridge addresses
  1023→* Internal service hostnames
  1024→
  1025→Explicitly block destinations such as:
  1026→
  1027→```text
  1028→127.0.0.0/8
  1029→10.0.0.0/8
  1030→172.16.0.0/12
  1031→192.168.0.0/16
  1032→169.254.0.0/16
  1033→::1/128
  1034→fc00::/7
  1035→fe80::/10
  1036→169.254.169.254
  1037→metadata.google.internal
  1038→```
  1039→
  1040→Use a complete maintained IP classification implementation, not only this example list.
  1041→
  1042→## 11.3 DNS rebinding protection
  1043→
  1044→Protect against DNS rebinding:
  1045→
  1046→* Resolve before execution.
  1047→* Record approved public IPs.
  1048→* Re-resolve before connecting.
  1049→* Revalidate redirects.
  1050→* Revalidate subresources where enforcement is possible.
  1051→* Abort if the host changes to an unsafe address.
  1052→* Use an egress proxy or network policy as a second defense.
  1053→* Do not trust DNS validation alone.
  1054→
  1055→## 11.4 Redirect policy
  1056→
  1057→* Maximum ten redirects.
  1058→* Validate every redirect target.
  1059→* Deep scans may only remain inside verified allowed origins.
  1060→* External third-party resources may be loaded only under a restrictive policy.
  1061→* Navigation to an unverified external origin must be blocked.
  1062→* Record blocked redirects as scan events.
  1063→
  1064→## 11.5 Scan authorization
  1065→
  1066→Before every deep run, verify:
  1067→
  1068→* Workspace has access to the project.
  1069→* Domain remains verified.
  1070→* Subscription allows the run.
  1071→* User explicitly confirms authorization.
  1072→* Environment is enabled.
  1073→* Target passes SSRF validation.
  1074→

  1077→# 12. BROWSER WORKER SANDBOX
  1078→
  1079→Browser workers process hostile websites and must be isolated.
  1080→
  1081→Run every scan in an ephemeral isolated container or equivalent isolated workload.
  1082→
  1083→Requirements:
  1084→
  1085→* Run as a non-root user.
  1086→* Read-only root filesystem.
  1087→* Writable temporary directory only through tmpfs.
  1088→* Drop all Linux capabilities.
  1089→* Enable no-new-privileges.
  1090→* Use default or stricter seccomp policy.
  1091→* Use AppArmor or equivalent where available.
  1092→* Never mount Docker socket.
  1093→* Never mount host credentials.
  1094→* Never use host networking.
  1095→* Never expose database credentials directly to the browser process.
  1096→* Enforce CPU limits.
  1097→* Enforce memory limits.
  1098→* Enforce PID limits.
  1099→* Enforce execution timeout.
  1100→* Enforce page count limits.
  1101→* Enforce response size limits.
  1102→* Enforce download limits.
  1103→* Disable browser downloads unless explicitly required.
  1104→* Destroy the container after every run.
  1105→* Delete temporary files after artifact upload.
  1106→* Use separate browser contexts per run.
  1107→* Never reuse cookies between customers.
  1108→* Never reuse authenticated browser state between workspaces.
  1109→
  1110→Use a pinned official Playwright container image compatible with the installed Playwright version.
  1111→
  1112→## 12.1 Browser launch policy
  1113→
  1114→Apply safe browser launch configuration.
  1115→
  1116→Do not casually use unsafe flags such as:
  1117→
  1118→```text
  1119→--no-sandbox
  1120→```
  1121→
  1122→If the runtime platform requires a specific sandbox configuration, implement and document a secure platform-specific approach.
  1123→
  1124→Block:
  1125→
  1126→* Service-worker persistence across runs
  1127→* Persistent profiles
  1128→* Clipboard access unless required
  1129→* Camera
  1130→* Microphone
  1131→* Geolocation unless explicitly configured
  1132→* Notifications
  1133→* Uncontrolled downloads
  1134→
  1135→## 12.2 Network interception
  1136→
  1137→Intercept browser requests.
  1138→
  1139→Enforce:
  1140→
  1141→* Allowed navigation origins
  1142→* Blocked internal IPs
  1143→* Maximum response size
  1144→* Request timeout
  1145→* Blocked protocols
  1146→* Redirect revalidation
  1147→* Optional third-party tracker blocking
  1148→* Sensitive header stripping on cross-origin requests
  1149→* No Authorization header forwarding to unrelated origins
  1150→
  1151→Log blocked requests without logging secrets.

  1159→## 13.1 Pipeline
  1160→
  1161→A run must perform these stages:
  1162→
  1163→1. Validate request and quota.
  1164→2. Validate ownership and target URL.
  1165→3. Create immutable run configuration snapshot.
  1166→4. Enqueue run.
  1167→5. Allocate isolated worker.
  1168→6. Launch Playwright.
  1169→7. Crawl allowed pages.
  1170→8. Execute page analyzers.
  1171→9. Execute configured viewports.
  1172→10. Execute configured locales.
  1173→11. Execute safe journeys.
  1174→12. Capture artifacts.
  1175→13. Deduplicate findings.
  1176→14. Calculate severity.
  1177→15. Enrich selected findings using AI.
  1178→16. Calculate project score.
  1179→17. Generate report.
  1180→18. Persist usage.
  1181→19. Send notifications.
  1182→20. Destroy worker environment.
  1183→
  1184→## 13.2 Crawl rules
  1185→
  1186→Crawler requirements:
  1187→
  1188→* Start from base URL.
  1189→* Stay inside allowed verified origins.
  1190→* Respect configured maximum depth.
  1191→* Respect maximum pages.
  1192→* Normalize URLs.
  1193→* Ignore fragments.
  1194→* Avoid duplicate query permutations.
  1195→* Allow configured ignored query parameters.
  1196→* Avoid calendar traps and infinite pagination.
  1197→* Detect logout links and avoid them by default.
  1198→* Detect dangerous actions.
  1199→* Do not click destructive buttons.
  1200→* Do not submit forms during basic crawl.
  1201→* Maintain visited and queued URL sets.
  1202→* Enforce per-page and total timeout.
  1203→* Record HTTP status and content type.
  1204→* Skip unsupported binary content.
  1205→* Record canonical URL.
  1206→* Record page title.
  1207→* Record language and direction.
  1208→* Record redirect chain.
  1209→
  1210→Allow configurable include and exclude patterns.
